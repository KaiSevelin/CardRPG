Card RPG

A tabletop role-playing game played with cards instead of dice.

Every character carries two decks — what they can do, and what the world does back. There are no dice and no attributes: a card is both the thing you are good at and the thing you spend to use it, so an adventuring day runs out rather than resetting.

Read the player's handbook

26 chapters, 84 tables, 338 pieces of art. One page — it is long, and it is meant to be read in a browser.

The game runs as a system for Foundry VTT, which lives in this repository alongside the handbook it is built from. The source is on GitHub.
